# Демо 3. AI в офісі: Docs та Gmail

**Сервіс:** Google Docs / Gmail (Gemini). **Формат:** ⏩ швидко / за потреби.
> Для службового листування — робочий акаунт організації, не особистий Gmail.

## Docs — абзац для переписування (вставити в документ)
> Доводимо до Вашого відома, що у зв'язку з необхідністю проведення відповідних заходів,
> спрямованих на покращення функціонування системи, буде здійснено певні дії у відповідні
> терміни, про що буде повідомлено додатково у встановленому порядку.

**Промпт:** `Перепиши цей абзац офіційно, коротше і зрозуміліше.`

## Gmail — приклад листування для підсумку (вставити або взяти реальний робочий тред)
> — Добрий день! Чи готові документи по закупівлі лавок?
> — Частково, чекаємо рахунок від постачальника.
> — Коли орієнтовно?
> — До кінця тижня, тоді підпишемо договір і оплатимо.
> — Добре, тримайте в курсі щодо дати встановлення.

**Промпт:** `Підсумуй це листування: ключові домовленості й відкриті питання списком.`

## Наголос
Це вбудовано у звичний інструмент — нічого не треба встановлювати.
