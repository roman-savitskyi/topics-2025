# Демо 4. Аналіз бюджету громади

**Сервіс:** Google Sheets + Gemini (або вставити таблицю в ChatGPT).
**Дані:** `04-byudzhet.xlsx` — відкрити в Excel або завантажити в Google Sheets (Файл → Імпорт).

## Промпт (копіювати)
```
Ось таблиця видатків громади за рік. 1) Зроби коротке зведення за напрямами;
2) познач три найбільші статті; 3) поясни простою мовою для мешканців, куди пішли гроші;
4) запропонуй, який графік це найкраще покаже.
```

## Очікуваний результат (приклад)
- Найбільші статті: **Освіта — 47%**, ЖКГ — 23%, Управління — 12%. Разом > 80%.
- Простими словами: майже половина грошей — на школи й садочки, чверть — на воду,
  дороги та благоустрій.
- Графік: стовпчикова діаграма за напрямами.

## Наголос
Дані бюджету відкриті — персональних даних немає, заливати безпечно.
Альтернатива без AI: у Sheets вбудоване «Аналізувати дані» → графік одним кліком.
