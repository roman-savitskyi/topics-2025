# Демо 5. Excel / Sheets без болю (гібрид)

**Сервіс:** Google Sheets / Excel + AI-помічник. **Формат:** ⏩ швидко / за потреби.

## Частина А — вбудоване (без AI)
Дані: `05-excel-oplata.csv`.
- **Зведена таблиця (pivot):** сума за статусом «Оплачено / Не оплачено».
- **«Аналізувати дані»** (Sheets) / «Аналіз даних» (Excel) — підсумки й графік одним кліком.
- Ключові формули: `СУМЕСЛИ/SUMIF`, `ВПР/XLOOKUP`, `FILTER`.

## Частина Б — AI-помічник

**Формула на замовлення** (промпт):
```
Напиши формулу для Google Sheets/Excel, яка підсумує суму з колонки C,
якщо в колонці B стоїть «Оплачено».
```
Результат: `=SUMIF(B:B; "Оплачено"; C:C)` (укр. локаль: `=СУМЕСЛИ(B:B;"Оплачено";C:C)`)

**Пояснити чужу формулу** (промпт):
```
Поясни простими словами, що робить ця формула: =ЕСЛИ(И(A2>0;B2<>"");"так";"ні")
```

**Прибрати безлад** — дані `05-excel-pib.csv` (промпт):
```
Ось стовпець із ПІБ одним рядком (є зайві пробіли й різний регістр). Запропонуй, як
розділити його на прізвище, ім'я та по батькові в окремі колонки й уніфікувати регістр.
```
