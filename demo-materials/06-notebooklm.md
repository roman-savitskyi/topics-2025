# Демо 6. NotebookLM — база знань громади

**Сервіс:** NotebookLM (notebooklm.google.com).

## Підготовка (заздалегідь)
Завантажити в новий ноутбук документ `06-statut-hromady.md` (а для реального демо —
справжні статут, регламент ради, положення).

## Питання наживо (копіювати)
```
Який порядок скликання позачергової сесії ради? Дай відповідь із посиланням на
конкретний пункт документа.
```

## Що показати
1. Відповідь **із клікабельним посиланням** на конкретний пункт (3.3–3.4) — можна
   перевірити за 5 секунд.
2. Друге питання за бажанням: `За скільки днів повідомляють населення про сесію?` (п. 3.5).
3. **Родзинка:** увімкнути Audio Overview — двоголосий аудіоогляд документа.

## Наголос
Ґрунтування на джерелах різко знижує вигадування, але не гарантує нуля — тому відповіді
з посиланням, які легко перевірити.
