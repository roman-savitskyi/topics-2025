# Демо 8. Власний асистент громади (Gemini Spark)

**Сервіс:** Gemini → Spark (створення власного асистента). **Формат:** ⏩ швидко / за потреби.
> Створення Spark — безкоштовне. Custom GPT (ChatGPT) — потребує платного тарифу.

## Інструкція для Spark (копіювати в поле Instructions)
```
Ти — «Помічник діловодства Соснівської громади». Допомагаєш готувати офіційні листи,
відповіді на звернення та проєкти розпоряджень. Стиль — офіційно-діловий, українською.
Дотримуйся правил: не вигадуй номерів законів і дат, не проси персональних даних, за
браку інформації — уточнюй.
```

## Що показати
Відкрити готовий Spark → одразу дати звернення (без пояснення контексту) → отримати
відповідь у потрібному форматі. Налаштували раз — користується весь відділ.
