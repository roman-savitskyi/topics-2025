# Демо 9. Запис засідання → протокол

**Сервіс:** NotebookLM / Gemini. **Формат:** ⏩ швидко / за потреби.

## Варіант наживо
Записати диктофоном телефона 30–60 сек → завантажити аудіо в NotebookLM або Gemini →
отримати транскрипцію → застосувати промпт нижче. (Зшивається з демо NotebookLM.)

## Готова стенограма (УМОВНА — якщо немає часу на запис)
> — Колеги, розпочинаємо. Присутні: голова, заступник, секретар, троє членів виконкому.
> Перше питання — ремонт освітлення на Шевченка.
> — Пропоную доручити відділу ЖКГ, термін місяць.
> — Підтримуємо. Друге — оголошення про відключення води на Центральній 25 числа.
> — Треба підготувати оголошення для мешканців і розмістити на сайті та у групі.
> — Відповідальний — прес-секретар, до 20 числа. Голосуємо. Одноголосно. Дякую, засідання
> закрито.

## Промпт (копіювати)
```
Ось стенограма засідання виконкому. Склади проєкт протоколу: присутні, порядок денний,
ухвалені рішення, відповідальні. Окремо виділи всі доручення зі строками.
```

## Обережно
У реальному записі можуть бути персональні дані — попередьте учасників.
