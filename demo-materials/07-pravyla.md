# Демо 7. Правила (custom instructions)

**Сервіс:** ChatGPT (Settings → Personalization → Custom instructions) або
Gemini (Saved info). **Формат:** ⏩ швидко / за потреби.

## Правила (копіювати в налаштування)
```
Завжди відповідай українською в офіційно-діловому стилі. Дотримуйся структури ділового
листа. Ніколи не вигадуй номери законів, дати та ПІБ. Якщо даних бракує — постав
уточнювальні питання. Ніколи не проси персональних даних громадян.
```

## Що показати
Той самий запит **без правил** і **з правилами** — різниця в стабільності та стилі.
Правила прописуються раз і діють у кожному наступному запиті.
