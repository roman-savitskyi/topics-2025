# Демо 2. Проєкт розпорядження з кількох тез

**Сервіс:** ChatGPT / Gemini. **Формат:** ⏩ швидко / за потреби.

## Промпт (копіювати)
```
Склади проєкт розпорядження голови громади на основі тез:
1) організувати ремонт вуличного освітлення на вул. Шевченка;
2) відповідальний — відділ ЖКГ;
3) термін виконання — 30 днів;
4) контроль залишити за собою.
Дай офіційну структуру: преамбула, пункти, відповідальні, контроль.
Місця для номера й дати познач як [___].
```

## Очікуваний результат (приклад)
```
РОЗПОРЯДЖЕННЯ голови Соснівської громади № [___] від [___]
Про організацію ремонту вуличного освітлення на вул. Шевченка

З метою забезпечення безпеки мешканців:
1. Відділу ЖКГ організувати ремонт вуличного освітлення на вул. Шевченка у строк до 30 днів.
2. Відповідальним за виконання призначити начальника відділу ЖКГ.
3. Контроль за виконанням залишаю за собою.

Голова громади    [підпис]    [ПІБ]
```

## Наголос
AI дає структуру за секунди; реквізити, строки та відповідність нормам перевіряє людина.
Юридичну силу надає підпис (КЕП), а не сервіс.
