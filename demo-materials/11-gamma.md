**Сервіс:** Gamma (gamma.app) / Canva. **Формат:** ⏩ швидко / за потреби.

## Текст для генерації (копіювати)
```
Зроби коротке оголошення для мешканців: 25 числа з 09:00 до 15:00 не буде водопостачання
на вул. Центральній через планові роботи. Додай заголовок, дату, час і контакт для питань.
```

## Що показати
Вставити текст → Gamma/Canva генерує готовий візуальний пост/слайд для сайту чи соцмереж.
