Наукова новизна

Вперше:

Індекс когнітивної доступності тексту (ІКД) — інтегральний нормований показник, що поєднує лексичний, синтаксичний і компонент читабельності в єдиній шкалі, адаптованій для української мови та цільової групи користувачів
Алгоритм визначення стабільної емоції — на основі розпізнавання виразу обличчя через відеокамеру пристрою в реальному часі, що дозволяє використовувати емоційний стан як індикатор когнітивного навантаження
Алгоритм забезпечення вебдоступності тексту — поєднує статичний аналіз ІКД з динамічним управлінням на основі стабілізованої емоції та спрощенні тексту
Спеціалізовані словники синонімічних замін лексики окремих категорій для української мови, що забезпечують лексичну оптимізацію вебконтенту

Практичне значення

Програмний комплекс — реалізує повний цикл від аналізу когнітивної складності до ітераційного спрощення та може бути впроваджений як інструмент підтримки читання для осіб з когнітивними та інтелектуальними порушеннями
ІКД як самостійний інструмент — кількісне оцінювання складності тексту, адаптований для морфологічних та синтаксичних особливостей української мови; може застосовуватися для оцінювання навчальних матеріалів та вебконтенту
Словники синонімічних замін — 7 категорій проблемної лексики з детермінованою ієрархією підстановок та морфологічним узгодженням; лінгвістичний ресурс для повторного використання в інших NLP-системах
Модуль розпізнавання емоцій — двоканальна стабілізація з програмною калібруванням на базі телеметричного корпусу; може використовуватися як самостійний компонент неінвазивного моніторингу когнітивного навантаження

Індекс когнітивної доступності (ІКД)

ІКД = w₁·Lex + w₂·Syn + w₃·Read

де Lex, Syn, Read ∈ [0; 1],  w₁ + w₂ + w₃ = 1

Lex (w₁ = 0,40) — лексичний компонент: рідковживані слова, терміни, абревіатури, сленг, архаїзми, ненормативна лексика
Syn (w₂ = 0,35) — синтаксичний: глибина вкладеності, підрядні конструкції, довжина ланцюжків залежностей
Read (w₃ = 0,25) — читабельність: FKukr, SMOGukr, D-Levelukr (калібровані для укр. мови)

Висновки

1. Комплексний аналіз наявних методів показав, що класичні індекси читабельності не забезпечують діагностичної повноти для когнітивних бар'єрів і непридатні для морфологічно складних мов. Обґрунтовано гібридний підхід.
2. Розроблено індекс когнітивної доступності (ІКД) — інтегральний показник [0; 1] з лексичним, синтаксичним та компонентом читабельності. ІКД зафіксував покращення у 10/10 текстів, класичні індекси — 0/10.
3. Розроблено метод визначення стабільної емоції на основі FER у реальному часі з чотирма каналами агрегації та правилом негативного консенсусу.
4. Розроблено узагальнений метод забезпечення вебдоступності тексту — ітераційний процес: ІКД → детекція → ранжування 7 категорій → трансформації → контроль семантики.
5. Програмна реалізація: браузерний комплекс з трирівневою архітектурою. Проведено 7 експериментів: конвергенція за 1–3 ітерації, семантика збережена (cos sim 0,918), масштабованість O(n1.30).
